# Residential Extension & Fence

Draft client presentation with a carport, upper deck and stair, service spaces and perimeter works. Nine protected drawing previews cover site planning, architecture, structure, electrical and plumbing.

Project Presentation: Engr. Jose Joaquin Valerio, MEnM, RCE, RMP

Drawing previews are watermarked derivatives. Private title blocks, survey identifiers and location maps are omitted. Original PDF and native Revit files are not distributed here.

The final page section includes the authorized 33-second REV R native Revit walkthrough, with a poster preview and browser playback controls. The video loads when the viewer chooses to play it.
